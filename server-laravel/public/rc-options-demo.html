선호도별 호텔/룸타입

1기간 · 인원

2확인할 호텔 · 룸타입

같은 기간에 여러 호텔 또는 같은 호텔의 다른 룸타입을 선호도 순으로 등록합니다.
1순위가 마감이어도 확인자가 2·3순위를 이어서 확인해 부킹 기회를 늘립니다.
객실 수는 위 기본값이 적용되며, 호텔별로 다르게 잡고 싶으면 아래에서 개별 입력하세요.

기존 방식과의 차이
전에는 요청 1건 = 호텔 1개 + 룸타입 1개였습니다. 마감이면 요청자가 다시 등록 → 확인자가 다시 확인하는 왕복이 필요했습니다. 이제 한 번에 여러 후보를 올려 한 번의 확인으로 대안까지 받습니다.

2요청 #A-1042 · 가능여부 입력

각 후보마다 가능 / 불가를 선택하고, 가능한 경우 1박 단가를 입력합니다. 1순위가 불가여도 아래 후보를 이어서 확인해 주세요.

3확인 결과

가능한 후보 중 하나를 선택하면 그 옵션으로 견적서가 만들어집니다.
