에이전트 관리

에이전트 아이디·비밀번호는 니르바나에서만 발급합니다. 관리자는 만들거나 바꾸지 않고, 이용 여부만 정합니다.

직원 계정 발행

직원의 비밀번호는 본인이 회원정보에서 바꿉니다. 관리자는 처음 한 번만 초기 비밀번호를 정해 전달합니다. 잊었을 때는 아래 목록에서 재발급하세요.
역할
관할 지역

카오락 + 푸켓 = 카오락 · 푸켓 · 크라비 · 사무이 · 방콕
방콕 + 파타야 = 방콕 · 파타야
방콕은 양쪽 모두에 보입니다. 표에 없는 지역은 카오락 + 푸켓 담당이 맡습니다.

언어
이름
아이디 (이메일 또는 영문 아이디)
비밀번호 (6자 이상)

발행 즉시 승인 상태로 로그인할 수 있습니다. 아이디·비밀번호를 직원에게 전달하세요. 비밀번호는 직원이 회원정보에서 직접 변경할 수 있습니다.
